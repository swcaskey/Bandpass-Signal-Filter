# Bandpass Signal Filter

This project implements a 4th-order Chebyshev bandpass filter for tone isolation in radio receiver applications. The design demonstrates analog circuit analysis, simulation, and experimental validation.

## Overview
- Designed and constructed as a final project for Principles of Electrical Engineering II.
- Objective: Isolate 100 Hz Morse Code tones with minimal noise and precise selectivity.
- Implemented using cascaded op-amp stages with Chebyshev response characteristics.

## Technical Details
- Filter Type: 4th-order Chebyshev Bandpass  
- Center Frequency: 100.7 Hz  
- Quality Factor (Q): ≈7  
- Passband Ripple: 0.5 dB  
- Modeled in LTSpice; verified experimentally with oscilloscope.

## Validation
- LTSpice simulations confirmed predicted frequency response.
- Breadboard circuit produced a measured passband centered near the design target.
- Output displayed stable gain and minimal distortion at resonance.
